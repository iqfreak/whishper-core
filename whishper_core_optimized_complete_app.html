Gaming coexistence

  • SetPriorityClass(BELOW_NORMAL 0x4000) + capture SetThreadPriority(0), ASR -1 — Windows CPU only; GPU is time-sliced so keep kernels short (tiny 6–9 ms vs small 12–18 ms).
  • Bounded queues: asr 2, translate 8 — backpressure drops oldest, never grows unbounded.
  • cpu_threads=2, beam1, without_timestamps, vad_filter=False, condition_on_previous_text=False.
  • CUDA allocator cuda_malloc_async observed; DLLs via os.add_dll_directory(nvidia/*/bin) cached.

Research — how to stay <100 ms and make it a complete app

  • True streaming vs pseudo: Whisper sliding-window is 0.5–1.0 s blocks (not causal) — falls apart at 0.5 s (RTF 3). Causal transducer (Sherpa CreateOnlineRecognizer, FastConformer 80 ms) is the 80 ms chunk path; keep Whisper for quality tier, transducer for <100 ms tier.
  • Capture: IAudioClient3::GetSharedModeEnginePeriod → 10 ms saves ~240 ms vs legacy WASAPI 50 ms poll; mean-decimate 48k→16k 0.08 ms, NOT Rubato Sinc (10× heavy).
  • VAD gating before ASR: Silero via sherpa-onnx 0.6 ms/30 ms — gate capture→ASR, don't send silence to CUDA.
  • Overlay: 33 ms coalesce (2× 60 fps frame) is correct; 16 ms timer would halve frame budget headroom but costs wakeups. Keep tier A (windowed/borderless); exclusive fullscreen out of scope (anti-cheat).
  • Translation: task=translate = one pass English; otherwise pipeline queues translate off hot path — partial shows immediately, final updates same id (never a new row).
